## ✦ About

This project showcases multiple **CSS animations**, including color changes, movement, rotation, scaling, fading, spinning, and bouncing effects.

---

## ✦ Features

* Color changing animation
* Moving box
* Rotating box
* Pulse/scale effect
* Fade effect
* Loading spinner
* Square path animation
* Bouncing colored dots

---
